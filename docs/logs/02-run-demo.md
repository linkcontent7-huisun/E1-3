# 02. 실행 결과 로그 (실제 실행 출력)

입력은 파이프(`printf`)로 넣었기 때문에 입력한 값은 화면에 나타나지 않고 프롬프트만 이어서 보인다. 성능 시간은 실행마다 조금씩 달라진다.

## A. 모드 1: 명세 예시 입력 (기대: A 1.0, B 5.0, 판정 B)

모드 1 선택 → 필터 A, 필터 B, 패턴을 한 줄씩 입력한다.

```
$ python main.py
=== Mini NPU Simulator ===

[모드 선택]

1. 사용자 입력 (3x3)
2. data.json 분석
3. 패턴 생성기 (보너스)
선택: 
#----------------------------------------
# [1] 필터 입력
#----------------------------------------
필터 A (3줄 입력, 공백 구분)
필터 A 1행: 필터 A 2행: 필터 A 3행: 필터 B (3줄 입력, 공백 구분)
필터 B 1행: 필터 B 2행: 필터 B 3행: 
#----------------------------------------
# [2] 패턴 입력
#----------------------------------------
패턴 (3줄 입력, 공백 구분)
패턴 1행: 패턴 2행: 패턴 3행: 
#----------------------------------------
# [3] MAC 결과
#----------------------------------------
A 점수: 1.0
B 점수: 5.0
연산 시간(평균/10회): 0.0012 ms (A), 0.0011 ms (B)
판정: B

#----------------------------------------
# [4] 성능 분석 (3×3)
#----------------------------------------
크기     평균 시간(ms)   연산 횟수
-------------------------------------
3×3      0.0010          9
```

## B. 모드 1: 잘못된 입력 재입력

행 개수 틀림(1 2), 열 개수 틀림(1 2 3 4), 숫자 아님(a b c), 빈 줄 순서로 넣은 뒤 올바른 줄을 넣는다.

```
$ python main.py
=== Mini NPU Simulator ===

[모드 선택]

1. 사용자 입력 (3x3)
2. data.json 분석
3. 패턴 생성기 (보너스)
선택: 
#----------------------------------------
# [1] 필터 입력
#----------------------------------------
필터 A (3줄 입력, 공백 구분)
필터 A 1행: 입력 형식 오류: 각 줄에 3개의 숫자를 공백으로 구분해 입력하세요.
필터 A 1행: 입력 형식 오류: 각 줄에 3개의 숫자를 공백으로 구분해 입력하세요.
필터 A 1행: 입력 형식 오류: 숫자만 입력하세요. (예: 0 1 0)
필터 A 1행: 입력 형식 오류: 각 줄에 3개의 숫자를 공백으로 구분해 입력하세요.
필터 A 1행: 필터 A 2행: 필터 A 3행: 필터 B (3줄 입력, 공백 구분)
필터 B 1행: 필터 B 2행: 필터 B 3행:

# [2] 패턴 입력

패턴 (3줄 입력, 공백 구분)
패턴 1행: 패턴 2행: 패턴 3행: 
#----------------------------------------
# [3] MAC 결과
#----------------------------------------
A 점수: 1.0
B 점수: 5.0
연산 시간(평균/10회): 0.0011 ms (A), 0.0011 ms (B)
판정: B

#----------------------------------------
# [4] 성능 분석 (3×3)
#----------------------------------------
크기     평균 시간(ms)   연산 횟수
-------------------------------------
3×3      0.0011          9
```

## D. 모드 3: 패턴 생성기

잘못된 N(4, abc)을 두 번 넣은 뒤 N=5를 입력한다.

선택: 
패턴 크기 N (홀수, 3~25): ⚠️ 잘못된 입력입니다. 3~25 사이의 홀수를 입력하세요.
패턴 크기 N (홀수, 3~25): ⚠️ 잘못된 입력입니다. 3~25 사이의 홀수를 입력하세요.
패턴 크기 N (홀수, 3~25):

## E. data.json이 깨진 경우 (프로그램은 죽지 않는다)

data.json 내용을 `{깨진 json`으로 바꾼 복사본 폴더에서 실행했다(원본 data.json은 건드리지 않음).

```
$ python main.py
=== Mini NPU Simulator ===

[모드 선택]

1. 사용자 입력 (3x3)
2. data.json 분석
3. 패턴 생성기 (보너스)
선택: ⚠️ data.json을 읽을 수 없습니다: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
```
